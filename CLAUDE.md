# Rules for coding agents in this repo

- Run `python3 run_all.py` before and after any change. All checks must pass, and say
  which numbers moved and why.
- A check must be able to fail. When adding one, show it failing once (a mutant, a
  wrong value) before trusting it passing.
- Units on every number, in code comments, plots and the README.
- Every simplification (ideal switch, generic model, missing block) is stated in the
  README under "What this is not".
- Results in `results/` are regenerated by the scripts, never edited by hand.
- Public repo: no personal contact details, nothing confidential from any employer or
  industry project. Only published work may be referenced.
- Private notes and links live in `CLAUDE.local.md` (gitignored); read it if present.
